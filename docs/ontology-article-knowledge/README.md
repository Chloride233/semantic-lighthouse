# Ontology Article Knowledge Base

This folder is an Obsidian-style knowledge base distilled from 51 articles in `D:/Ontology article/数据思考`.

The source articles are not copied into the repository. The notes preserve source title, date, URL, and local path in [[source-index]], then synthesize project-relevant ideas in [[synthesis]] and [[semantic-lighthouse-fit]].

## Reading Protocol

- Source fidelity first: each article is represented in [[source-index]] with a concise, source-bound takeaway.
- Synthesis second: cross-article claims in [[synthesis]] reference article IDs such as `A18` or `A42`.
- Project fit last: [[semantic-lighthouse-fit]] maps the absorbed ideas to current Semantic Lighthouse boundaries and possible next decisions.
- Claims marked as "project inference" are not direct article claims; they are implications for this repository.

## High-Level Thesis

The article set repeatedly argues that enterprise AI value is blocked less by model capability and more by semantic infrastructure, governance, accountability, and operating model. In this framing, an AI-ready enterprise needs a semantic asset base made of ontology, metrics, mappings, rules, evidence, versioning, and human review loops. RAG and knowledge bases help with retrieval, but they do not by themselves create machine-usable business meaning or safe action.
