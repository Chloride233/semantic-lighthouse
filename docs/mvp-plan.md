# Semantic Lighthouse MVP Plan

## 2 周 MVP 目标

做一个能用于求职展示的最小企业 AI 转型顾问 Agent 原型。

## 输入

- 客户问题，例如：我们已经有数据中台，为什么还需要 Ontology？
- 或客户画像：行业、规模、现有系统、数据基础、痛点、预算、约束

## 输出

- 面向客户的咨询式回答
- 引用来源：概念、案例、方法论、方案
- 可信度：高 / 中 / 低
- 知识库缺口：建议新增或补强的实体
- 下一步建议：试点场景、3 个月路线图、风险提示

## 第 1 周

- 建立 Markdown 知识库读取与检索
- 支持按标题、路径、frontmatter、正文关键词召回实体
- 设计 10 个测试问题
- 输出带引用的回答草稿

## 第 2 周

- 接入大模型生成最终回答
- 增加可信度和知识缺口判断
- 保存 10 个测试问题的回答样本
- 准备求职展示用 README、架构图和 2 分钟项目介绍

## 不做

- 不做完整产品化
- 不做用户系统
- 不做复杂前端
- 不修改 `F:\ontology-kb` 的知识实体 schema
