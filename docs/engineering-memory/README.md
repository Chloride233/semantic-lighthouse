# Engineering Memory

This folder stores evidence of engineering growth for Semantic Lighthouse.

Do not write vague diary entries here. Each note should explain a real technical decision, risk, failure, fix, or verification result that can later support an interview story.

## Read Order For New Agents

1. `../agent-handoff.md`
2. `learning-index.md`
3. Latest version retrospective
4. Latest entries in `pitfall-log.md`
5. Latest entries in `highlight-log.md`
6. `interview-stories.md`

Use this structure for important entries:

```md
## Title

- Date:
- Version:
- Type: pitfall / highlight / decision / risk-control
- Context:
- What happened:
- Engineering judgment:
- Risk if ignored:
- Fix or control:
- Verification:
- Interview version:
```
